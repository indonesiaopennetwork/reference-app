Each file starts with the table list and the full ER diagram, followed by a section per table (columns, constraints, indexes, triggers and a diagram of its direct neighbours). Diagrams are inline [Mermaid](https://mermaid.js.org/), which GitHub renders.

## Regenerating

After adding or changing a migration:

```sh
task docs:db
```

This needs only Docker. It starts a throwaway Postgres, applies `bap-application/db/migrations` and `bpp-application/db/migrations` with the same `Dockerfile.migrate` images used in deployment, runs tbls with `bap-application/db/.tbls.yml` / `bpp-application/db/.tbls.yml`, merges tbls' per-table pages into one file per database (`scripts/merge-tbls-docs.sh`), then removes the container. Commit the updated `docs/db/`.
